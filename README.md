# Sales Dashboard – Power BI

## 📊 Project Overview
An interactive Power BI Sales Dashboard designed to analyze sales performance, quantity, orders, customers, product categories, monthly trends, and store-wise sales.

## 🛠️ Tools & Technologies
- Power BI
- MySQL
- SQL
- Data Visualization

## 📈 Dashboard Features
- Total Sales
- Total Quantity
- Total Orders
- Total Customers
- Sales by Category
- Sales Trend Over Time
- Store-wise Sales Analysis
- Customer-wise Filtering
- Year/Date Filtering

## 🗂️ Data Model
The project uses a dimensional data model consisting of:
- Fact Sales
- Customer Dimension
- Product Dimension
- Store Dimension
- Date Dimension
